# iRobapp
iRobapp（アイロバップ）は、AI（愛）＋ロボット＋アプリケーション の三位一体で生まれる、新しい相棒体験です。
1. このリポジトリの目的
• 	「iRobapp が利用する AI モデル（gguf）の配布ページです」
2. モデルの一覧とダウンロード方法
• 	Phi-3-mini
• 	Llama 3.2
• 	Releases からダウンロードできます
3. models/ フォルダの説明
• 	モデルの説明書
• 	ライセンス
• 	推奨量子化など
