# iRobapp Ver.1 アプリケーション仕様書（正式版）

## 1. 概要

iRobapp Ver.1 アプリケーションは、**iPhone（iOS）上で動作するロボット連携アプリ**であり、  
BLE 通信・モーション制御・会話機能・ジャイロ連動リアクションの管理を行う。

本仕様書は、アプリ側で実装すべき **UI／通信／制御ロジックの標準仕様** を定義する。

---

## 2. システム構成

### 2-1. 使用技術
- **SwiftUI**：UI レイヤー  
- **CoreBluetooth**：BLE 通信  
- **AVFoundation**：音声入力／音声再生  
- **クラウド AI API**：会話生成  
- **ローカルデータ管理**：ユーザー設定・ロボット情報

### 2-2. ロボットとの接続構成
- BLE Peripheral：ロボット  
- BLE Central：iPhone  
- 通信方式：GATT（Notify / Write）

---

## 3. アプリ画面仕様（UI）

### 3-1. ホーム画面
- ロボットの接続状態を表示  
- ロボットの簡易ステータス（電池・姿勢・感情）を表示  
- 主な操作ボタン  
  - 「会話する」  
  - 「モーション」  
  - 「設定」  

### 3-2. 会話画面
- 音声入力ボタン  
- ロボットの返答を吹き出し形式で表示  
- ロボットの感情モーションを連動表示  
- 会話ログをローカル保存（任意）

### 3-3. モーション画面
- 基本動作の実行ボタン  
  - 立つ  
  - 座る  
  - 伏せ  
  - 歩く  
  - 回る  
- 感情表現の実行ボタン  
  - 尻尾ふり  
  - 首ふり  
  - 喜びモーション  

### 3-4. 設定画面
- ロボットの名前変更  
- 体毛（スキン）設定  
- BLE 再接続  
- AI 会話モード設定  
- 安全設定（モーター負荷制限など）

## 4. BLE 通信仕様

### 4-1. キャラクタリスティック構成

| 種類 | 説明 |
|------|------|
| CMD_WRITE | ロボットへの指示（モーション・発話） |
| STATUS_NOTIFY | ロボットの状態通知（電池・姿勢・ジャイロ） |
| EVENT_NOTIFY | イベント通知（持ち上げ検出・じゃれあい検出） |

### 4-2. 通信フロー

#### 接続時
1. アプリがロボットのアドバタイズを検出  
2. ペアリング要求  
3. ロボットが「親」として iPhone を登録  
4. 初期ステータスを受信

#### モーション実行時
1. アプリ → CMD_WRITE  
2. ロボットがモーション開始  
3. ロボット → STATUS_NOTIFY（進行状況）

#### 会話時
1. アプリが音声入力  
2. AI API へ送信  
3. 返答をロボットへ CMD_WRITE（発話）  
4. ロボットが感情モーションを実行

## 5. ジャイロ連動リアクション制御

アプリはロボットからの **EVENT_NOTIFY（持ち上げ検出）** を受信し、  
重力方向に応じて以下のリアクションを選択する。

- 垂直 → ゆっくりバタバタ  
- 頭上 → ぶらーん  
- 頭下 → すばやくバタバタ  

アプリ側では以下を行う：

- ログ記録  
- 必要に応じてユーザーへ通知  
- リアクション中のモーション指示を抑制（安全制御）

---

## 6. 安全仕様（アプリ側）

- BLE 切断時はロボットを安全姿勢へ移行  
- モーション連打を防ぐため、連続指示のクールタイムを設定  
- 高温通知を受けた場合、休息モードへ移行  
- ロボットの電池残量が低下した場合、警告表示
